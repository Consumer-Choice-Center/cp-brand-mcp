# Deploy CP Brand MCP 0.8

CP supports two transports:

- `pnpm start`: full local/SSH stdio, **18 tools**, including rendering and file validation.
- `pnpm run start:http`: stateless public read-only HTTP, **7 tools**, at `/mcp`; health at `/healthz`.

Public HTTP follows CCC and WVA's model. It does not expose filesystem paths, uploads, rendering or downloads. See [deploy/README.md](deploy/README.md) for the separate CP service on the CCC server, private mounts, Caddy, DNS and rollback. The repository supplies deployment configuration; GitHub Actions does not deploy the live server.

## Local installation

Requires Node.js 22 or 24 and pnpm 11.25.0.

```sh
git clone https://github.com/Consumer-Choice-Center/cp-brand-mcp.git
cd cp-brand-mcp
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile
cp data/fonts.example.json data/fonts.local.json
```

Supply licensed Futura Medium, Proxima Nova Semibold and Proxima Nova Regular. Set their paths in `data/fonts.local.json`; relative paths resolve against that JSON's directory. Futura may be a TTC collection containing `Futura-Medium`. No fallback fonts are used. Font binaries and machine-local configuration are excluded from Git, npm archives and Docker images.

```sh
pnpm run audit:assets
pnpm test
pnpm run smoke
```

Configure the MCP client with `node /absolute/path/to/cp-brand-mcp/src/server.mjs`. Restart an existing CP connection after upgrading so it rediscovers the tools. `get_mcp_status` reports the running version, transport and asset health.

Optional environment variables:

- `CP_BRAND_FONT_CONFIG`: absolute font-configuration path.
- `CP_BRAND_OUTPUT_DIR`: writable output directory, default `deliverables/`.

New photographs belong in `inputs/`. Quote photos are supplied per request; social cutouts use real unbranded imagery. The MCP does not invoke an image model. Legacy one-pager imagery is generated by the calling assistant.

## HTTP locally

```sh
pnpm run start:http
# In another terminal:
node scripts/smoke-http.mjs http://127.0.0.1:8083/mcp
```

The default host is `127.0.0.1`, port 8083. Production uses Caddy on the external `archivebox_default` network, without a published container port. Public status redacts local directories and font-file paths. Fontless startup still serves guidelines/discovery; rendering always requires the exact licensed fonts. The HTTP smoke check expects the configured font/asset audit to pass.

## Container and private runtime fonts

```sh
python3 scripts/prepare-private-fonts.py --config data/fonts.local.json --output runtime-private
docker build -t cp-brand-mcp .
```

The helper creates private runtime mounts, a ZIP and bounded secret parts without printing their contents. The default Docker command starts HTTP. For full stdio rendering, mount private fonts, config, inputs and outputs, and override the command:

```sh
docker run --rm -i \
  -v "$PWD/runtime-private/config:/config:ro" \
  -v "$PWD/runtime-private/fonts:/fonts:ro" \
  -v "$PWD/inputs:/app/inputs" \
  -v "$PWD/deliverables:/app/deliverables" \
  cp-brand-mcp node src/server.mjs
```

Use `-i`, not `-t`, for MCP protocol traffic. On Linux, the mounted files/directories must be accessible to UID 1000. For an operator-controlled remote stdio session, use the command over `ssh -T` with the operator's own input/output directories.

## Private rendering CI

Public PR CI checks syntax, fontless portability, HTTP behavior, dependencies, packaging and Docker startup. The separate `Rendering regression checks` workflow runs the complete rendering/visual suite and stdio smoke test on trusted `main` pushes or manual runs on `main`.

Licensed font bytes are held in **encrypted GitHub Actions secrets**, not a public URL or repository file. The helper splits the base64 ZIP into parts smaller than GitHub's per-secret limit. Upload the generated files through stdin:

```sh
for secret_file in runtime-private/ci-secrets/CP_FONT_BUNDLE_*; do
  gh secret set "$(basename "$secret_file")" \
    --repo Consumer-Choice-Center/cp-brand-mcp < "$secret_file"
done
gh variable set CP_RENDER_CI_ENABLED --body true \
  --repo Consumer-Choice-Center/cp-brand-mcp
```

The workflow supports up to 16 parts, verifies `CP_FONT_BUNDLE_SHA256`, reconstructs only the three expected font files in the runner temporary directory, validates exact font identities, and removes the files afterward. It does not run private-font code on untrusted pull requests or upload font artifacts. If rotating to a smaller bundle, delete surplus numbered secrets before enabling the new bundle.

The GitHub font secrets supply CI only. The live server receives the private runtime font/config directories separately through an authenticated transfer as described in `deploy/README.md`.

## Updates

```sh
git pull --ff-only
pnpm install --frozen-lockfile
pnpm run audit:assets
pnpm test
pnpm run smoke
```

Tagged releases publish an npm-format archive and `ghcr.io/consumer-choice-center/cp-brand-mcp`. Neither contains licensed font binaries. The image defaults to HTTP; override it with `node src/server.mjs` for stdio.
