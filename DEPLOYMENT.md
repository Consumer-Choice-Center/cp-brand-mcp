# Deploy CP Brand MCP 0.10

CP supports two transports:

- `pnpm start`: full local/SSH stdio, **18 tools**, including rendering and file validation.
- `pnpm run start:http`: public HTTP with quote rendering, **8 tools**, at `/mcp`; health at `/healthz`.

Public HTTP follows CCC and WVA's model. It renders quotes with supplied portraits and provides temporary downloads, while excluding arbitrary filesystem paths and general-purpose uploads. See [HTTP quote workflow](docs/http-quotes.md). See [deploy/README.md](deploy/README.md) for the separate CP service on the CCC server, Caddy, DNS and rollback. The repository supplies deployment configuration; GitHub Actions does not deploy the live server.

## Local installation

Requires Node.js 22 or 24 and pnpm 11.25.0.

```sh
git clone https://github.com/Consumer-Choice-Center/cp-brand-mcp.git
cd cp-brand-mcp
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile
```

The checkout includes static Jost Medium and Montserrat Regular/SemiBold TTFs, their OFL notices, and fixed vector logos preserving the original Futura lettering. No Adobe activation or commercial font transfer is required. Source logos and finished references remain unchanged.

For upgrades, remove legacy `CP_BRAND_FONT_CONFIG` overrides and private font/config Docker mounts. `data/fonts.local.json` is no longer automatically loaded. The default `data/fonts.example.json` points to bundled fonts. An explicit custom configuration must use the same approved Jost/Montserrat PostScript identities; it cannot switch back to commercial originals.

```sh
pnpm run audit:assets
pnpm test
pnpm run smoke
```

Configure the MCP client with `node /absolute/path/to/cp-brand-mcp/src/server.mjs`. Restart an existing CP connection after upgrading so it rediscovers the tools. `get_mcp_status` reports the running version, transport and asset health.

Optional environment variables:

- `CP_BRAND_FONT_CONFIG`: optional configuration relocating the approved open-source faces; omit for bundled defaults.
- `CP_BRAND_OUTPUT_DIR`: writable output directory, default `deliverables/`.

New photographs belong in `inputs/`. Quote photos are supplied per request; social cutouts use real unbranded imagery. The MCP does not invoke an image model. Legacy one-pager imagery is generated by the calling assistant.

## HTTP locally

```sh
pnpm run start:http
# In another terminal:
node scripts/smoke-http.mjs http://127.0.0.1:8083/mcp
```

The default host is `127.0.0.1`, port 8083. Production uses Caddy on the external `archivebox_default` network, without a published container port. Public status redacts local directories and font-file paths. The image includes all required open fonts. Invalid explicit configurations fail rendering without preventing read-only discovery. The HTTP smoke check expects the configured font/asset audit to pass.

## Container

```sh
docker build -t cp-brand-mcp .
```

The default Docker command starts HTTP. For full stdio rendering, mount input/output directories and override the command:

```sh
docker run --rm -i \
  -v "$PWD/inputs:/app/inputs" \
  -v "$PWD/deliverables:/app/deliverables" \
  cp-brand-mcp node src/server.mjs
```

Use `-i`, not `-t`, for MCP protocol traffic. On Linux, mounted input/output directories must be accessible to UID 1000. Font files and original-logo outlines are already in the image. An operator-controlled remote session may run the same command over `ssh -T`.

## Rendering CI

CI uses bundled OFL fonts and fixed vector logos. The rendering workflow runs the complete rendering/visual suite and stdio smoke test on pushes, pull requests and manual runs. It needs no private font secrets or `CP_RENDER_CI_ENABLED` variable.

The legacy font provisioning scripts were removed. Existing `CP_FONT_BUNDLE_*` secrets and `CP_RENDER_CI_ENABLED` are no longer read; administrators can retire them separately. No commercial font bytes are included in repository/package/container artifacts.

## Updates

```sh
git pull --ff-only
pnpm install --frozen-lockfile
pnpm run audit:assets
pnpm test
pnpm run smoke
```

Tagged releases publish an npm-format archive and `ghcr.io/consumer-choice-center/cp-brand-mcp`. Both include only the three approved open-source TTFs with their OFL notices, plus fixed original-logo artwork. The image defaults to HTTP; override it with `node src/server.mjs` for stdio.
